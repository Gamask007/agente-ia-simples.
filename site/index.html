Um agente de IA que roda no seu computador

Você conversa no terminal, e o agente decide sozinho quando usar uma ferramenta: ver a hora, anotar tarefas ou listar arquivos do projeto. Tudo roda local, com o Ollama.

Você: anota que preciso estudar banco de dados

Agente: Pronto, anotei como tarefa 1.

Você: o que falta fazer?

Agente: 1. [ ] estudar banco de dados

Ferramentas

  • hora_atual: informa a data e a hora
  • anotar_tarefa, listar_tarefas e concluir_tarefa: uma lista de tarefas salva em arquivo
  • listar_pasta: lista arquivos, sem sair da pasta do projeto

Como usar

Instale o Ollama, baixe o modelo qwen2.5:3b, rode pip install -r requirements.txt e depois python agente.py. Os detalhes estão no README do repositório.
